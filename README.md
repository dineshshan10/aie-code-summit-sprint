# AIE Code Summit Sprint

Two weeks through all 50 AI Engineer Code Summit 2026 recordings (Nov 10-12, San Francisco), most important first.
Sprint: **Thu Nov 19 - Wed Dec 2, 2026**. Four talks a day for the first eight days, three a day after that.
Talks are ranked against three proposals submitted to this summit: eval harness for multi-agent workflows, context engineering as access control, and not letting every ticket reach the LLM.
Skim = read the illustrated essay or skim the transcript on the talk page. Deep = watch the full recording.
Progress is tracked in the AIE Code Summit Sprint artifact; this repo holds the daily notes, one file per day under `notes/`.
